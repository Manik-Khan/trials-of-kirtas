Supabase Transport Diagnostic

This page contains no Bardic clock code and no Supabase JavaScript library. It separately tests ordinary HTTPS access and a raw Realtime WebSocket upgrade.

Connection details

Never enter a service_role or sb_secret_… key. This tool does not print the key and does not store it in local storage.

Results

Not run HTTPS: Auth settings
Not run HTTPS: REST gateway
Not run WSS: Realtime socket

How to read it

  • HTTPS fails and WSS fails: project hostname, DNS, TLS, key, or general network path.
  • HTTPS passes but WSS fails: WebSocket upgrade is blocked, or the Realtime endpoint/service is failing.
  • WSS opens and heartbeat replies: raw transport works; return to the Supabase client/channel layer.
  • WSS opens then closes: copy the close code and reason from the log.
